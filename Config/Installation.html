Claude Personas

安装到“应用程序”

  1. 将磁盘窗口左侧的 Claude Personas 图标拖到右侧 Applications 文件夹。
  2. 等待复制完成，然后打开“访达 → 应用程序”中的 Claude Personas。
  3. 在菜单栏点击星号图标开始使用，最后推出此磁盘。

如果原来通过 Homebrew 安装，请先退出应用并运行 brew uninstall --cask claude-personas。普通卸载保留设置和账号数据。登录时启动及系统权限可能需要重新开启。

安裝到「應用程式」

將左側 Claude Personas 拖到右側 Applications 資料夾。複製完成後，從 Finder 的「應用程式」開啟，再退出此磁碟。原先使用 Homebrew 者應先結束 App 並以 brew uninstall 移除；設定及帳號資料會保留，登入啟動與系統權限可能需要重新啟用。

インストール

Claude Personas を右側の Applications フォルダにドラッグしてください。コピー完了後、Finder の「アプリケーション」から開き、ディスクを取り出します。Homebrew 版は先に終了して brew uninstall で削除してください。設定とアカウントデータは保持されます。ログイン時起動やシステム権限の再設定が必要な場合があります。

설치

Claude Personas를 오른쪽 Applications 폴더로 드래그하세요. 복사가 끝나면 Finder의 응용 프로그램에서 실행하고 디스크를 추출하세요. Homebrew 버전은 앱을 종료한 뒤 brew uninstall로 먼저 제거하세요. 설정과 계정 데이터는 유지됩니다. 로그인 시 실행 및 시스템 권한은 다시 설정해야 할 수 있습니다.

Install

  1. Drag Claude Personas onto the Applications folder on the right.
  2. Wait for copying to finish, then open Claude Personas from Finder → Applications.
  3. Click the asterisk in the menu bar to get started. Eject this disk when finished.

Switching from Homebrew? Quit the app and run brew uninstall --cask claude-personas first. Ordinary uninstall preserves settings and account data. Login items and system permissions may need to be enabled again.
