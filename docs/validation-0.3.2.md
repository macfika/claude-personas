## 修复依据

原生临时应用复现了 0.3.1 的遗漏：进程运行时未读取 `NSRunningApplication.launchDate`，退出后首次读取可能返回空值，导致本次更新退出记录被判为未知。运行时保存 PID 和启动时间后，同一场景能正确识别更新退出。

这证明了恢复识别中的真实漏洞；历史现场没有记录具体失败条件，不能把复现结果表述为对历史每次退出的完整重放。
