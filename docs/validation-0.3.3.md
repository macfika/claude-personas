# 0.3.3 验证记录

日期：2026-10-28。

## 问题与修复

- 默认配置先因更新退出、其他配置更晚退出时，旧时间判断可能把更新后重开的默认窗口视为多余并关闭。用相隔数小时的退出时间重放该判断，修复前返回了不应执行的关闭决定。
- 旧恢复候选列表明确排除了默认配置。先将原选择逻辑抽取到生产使用的入口，验证默认与命名配置同时有更新退出依据时，默认配置未被选中；修复后两者均可恢复。
- 移除了时间判断、自动关闭默认窗口路径及其状态，不再用猜测来结束默认账号进程。
- 默认配置现在同样检查本次更新退出记录，保留普通退出、用户主动退出和关闭恢复设置的边界。

历史日志没有记录旧自动关闭路径的具体调用，因此时间线吻合不能等同于已追溯到历史退出的调用者。

## 行为边界

Claude 更新可能自行额外打开默认窗口，现将保留它，由用户决定是否关闭。已关闭的历史配置不会仅因安装本版本而重新打开；恢复逻辑处理运行期间实际观察到的退出。真实 Claude 自更新后的默认配置恢复仍需端到端观察。
