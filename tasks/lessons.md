# 界面实现经验

- 新增设置行必须对照现有 SettingRow，复用相同的图标尺寸、文字起点、行间距和悬停效果。原生 Picker 自带标签不能替代布局中统一的标题；用独立标题、Spacer 和隐藏标签的 Picker 保持左右对齐。
- 视觉验收除了文字完整、切换可用，还要检查新旧行的左边缘、标题基线、右边缘及多语言下的布局。
- 自动更新必须按当前运行应用的安装来源分流；不能仅凭另一副本的 Caskroom 目录认定来源。更新错误必须可见，并对 Homebrew 受管副本在自动、手动和 CLI 入口统一阻止自更新。
- 单独验证下载、签名和替换不足以证明用户实际自更新正常；还应验证可发现的更新入口、错误反馈、运行应用的退出/替换/重启及包管理器版本一致性。
- 验证签名迁移应使用真实旧签名器交叉验签，不能要求 Ed25519 签名字节相等；CryptoKit 可能生成带随机性的有效签名。
- 面向普通用户的 macOS 发布不能只提供 ZIP；至少提供带明确安装图示的签名公证 DMG，并在下载页将用户安装与自动更新附件区分清楚。
- README、下载页和安装说明应围绕普通用户的安装、使用、更新及数据保留展开；发布、公证、密钥、CI 与验证过程放在开发者文档，不混入产品介绍或用户更新日志。支持应用自动更新时默认推荐 DMG，Homebrew 保留为可选方式。
